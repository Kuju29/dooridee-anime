โค้ด กีอัส การปฏิวัติของลูลูช ภาคที่ 2

โค้ด กีอัส การปฏิวัติของลูลูช ภาคที่ 2 (Code Geass: Lelouch of the Rebellion R2) ดูแบบถูกลิขสิทธิ์ในไทยได้ที่ Ani-One Thailand (ซับไทย), Bilibili (ซับไทย), Crunchyroll (ซับไทย), Crunchyroll (พากย์ไทย) จบแล้ว 25 ตอน

ชื่ออื่น: Code Geass: Lelouch of the Rebellion R2 / Code Geass: Hangyaku no Lelouch R2 / コードギアス 反逆のルルーシュ R2

ทีวีซีรีส์ · 2008 · Sunrise · จบแล้ว · 25 ตอน · คะแนน AniList 87/100

ประเภท: ต่อสู้, ดราม่า, หุ่นยนต์, ไซไฟ, ระทึกขวัญ

เรื่องย่อ

หนึ่งปีผ่านไปนับตั้งแต่ "The Black Rebellion" และอัศวินดำที่เหลือได้หายตัวไปในเงามืด Zero ผู้นำและหุ่นเชิดของพวกเขาถูกประหารชีวิตโดยจักรวรรดิบริทาเนียน พื้นที่ 11 กำลังดิ้นรนอีกครั้งภายใต้การกดขี่ของจักรพรรดิ ในขณะที่กองทัพบริทาเนียมุ่งความสนใจไปที่แนวรบยุโรป แต่สำหรับชาวบริทาเนียที่อาศัยอยู่ในแอเรีย 11 ชีวิตก็กลับมาเป็นปกติอีกครั้ง ในวันปกติวันหนึ่ง นักเรียนชาวอังกฤษคนหนึ่งโดดเรียนใน Ashford Academy และย่องออกไปเล่นหมากรุกเพื่อเล่นหมากรุก แต่ชายหนุ่มคนนี้ไม่รู้จัก กองกำลังหลายฝ่ายกำลังจับตามองเขาจากเงามืด ในไม่ช้า เขาจะต้องพบกับประสบการณ์ที่น่าตกใจกับอดีตที่ปิดบังของเขาเอง และซีโร่ จอมบงการกบฏสวมหน้ากากจะกลับมา
