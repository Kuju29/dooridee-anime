เรื่องย่อ

มาโกโตะ มิสุมิเป็นเพียงวัยรุ่นทั่วไปที่ถูกอัญเชิญไปยังอีกโลกหนึ่งในฐานะ "ฮีโร่" แต่เทพีแห่งโลกนี้เรียกเขาว่าน่าเกลียดและแย่งสถานะฮีโร่ของเขาไปจากเขาแล้วส่งเขาไปยังสุดขอบโลก ในดินแดนรกร้าง เขาได้พบกับมังกร แมงมุม ออร์ค คนแคระ และเผ่าพันธุ์อื่นที่ไม่ใช่มนุษย์ มาโกโตะแสดงสัญญาในการใช้เวทมนตร์และการต่อสู้ได้ ซึ่งเขาคงไม่สามารถทำได้ในโลกเก่าของเขา เขาเผชิญหน้ามามากมาย แต่เขาจะสามารถเอาชีวิตรอดจากโลกใหม่นี้ได้หรือไม่? แฟนตาซีที่ชายคนหนึ่งที่ถูกเทพเจ้าและมนุษยชาติทอดทิ้งพยายามจะเริ่มต้นชีวิตใหม่ในโลกใหม่นี้กำลังจะเริ่มต้นขึ้น!

วิดีโอที่เล่นบนเว็บนี้ใช้เครื่องเล่นของ YouTube (บางเรื่องเป็นของ SOOP) จากช่องของค่ายโดยตรง เว็บไม่ได้เก็บไฟล์วิดีโอไว้เอง ยอดวิวและโฆษณาบน YouTube เป็นของค่ายเหมือนดูในแอป YouTube · การฝังวิดีโอเป็นความสามารถของ YouTube เอง เจ้าของช่องเลือกเปิดหรือปิดได้ในการตั้งค่าของแต่ละคลิป ถ้าปิดไว้ เว็บจะพาไปดูที่ YouTube แทน · ค่ายที่ต้องการให้แก้ไขหรือนำเรื่องใดออก แจ้งได้ที่ GitHub หรือ อีเมล

รู้จักเว็บนี้กำลังฉายอนิเมะพากย์ไทยอนิเมะซับไทยแต่ละซีซั่นแยกตามค่ายแยกตามประเภททั้งหมด A-Z
