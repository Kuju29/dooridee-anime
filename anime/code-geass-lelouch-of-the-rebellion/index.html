โค้ด กีอัส การปฏิวัติของลูลูช

โค้ด กีอัส การปฏิวัติของลูลูช (Code Geass: Lelouch of the Rebellion) ดูแบบถูกลิขสิทธิ์ในไทยได้ที่ Ani-One Thailand (ซับไทย), Crunchyroll (ซับไทย), Crunchyroll (พากย์ไทย), Bilibili (ซับไทย) จบแล้ว 25 ตอน

ชื่ออื่น: Code Geass: Lelouch of the Rebellion / Code Geass: Hangyaku no Lelouch / コードギアス 反逆のルルーシュ

ทีวีซีรีส์ · 2006 · Sunrise · จบแล้ว · 25 ตอน · คะแนน AniList 85/100

ประเภท: ต่อสู้, ดราม่า, หุ่นยนต์, ไซไฟ, ระทึกขวัญ

เรื่องย่อ

ในวันที่ 10 สิงหาคม 2010 จักรวรรดิศักดิ์สิทธิ์แห่งบริแทนเนียได้เริ่มการรณรงค์พิชิต โดยมีจุดมุ่งหมายที่ประเทศญี่ปุ่น การปฏิบัติการเสร็จสิ้นภายในหนึ่งเดือนด้วยการติดตั้งยานเกราะฮิวแมนนอยด์เคลื่อนที่แบบใหม่ของ Britannia ซึ่งมีชื่อว่า Knightmare Frames สิทธิและอัตลักษณ์ของญี่ปุ่นถูกลิดรอนออกไป ประเทศที่ครั้งหนึ่งเคยภาคภูมิใจซึ่งปัจจุบันเรียกว่าแอเรีย 11 พลเมืองของประเทศนี้หรือ Elevens ถูกบังคับให้หาเลี้ยงชีพในขณะที่ชนชั้นสูงในบริแทนเนียใช้ชีวิตอย่างสะดวกสบายภายในถิ่นฐานของตน กลุ่มต่อต้านปรากฏขึ้นทั่วแอเรีย 11 เพื่อมุ่งสู่อิสรภาพของญี่ปุ่น ลูลูช เจ้าชายแห่งบริทันเนียที่ถูกเนรเทศโดยสวมรอยเป็นนักเรียน พบว่าตัวเองตกเป็นใจกลางของความขัดแย้งที่ดำเนินอยู่สำหรับประเทศหมู่เกาะแห่งนี้ ด้วยการพบกับหญิงสาวลึกลับชื่อซี.ซี. ลูลูชจึงได้รับกีอัสซึ่งเป็นพลังของราชา ตอนนี้ลูลูชมีพลังอำนาจเหนือกว่าใครก็ตาม ในที่สุดลูลูชก็อาจบรรลุเป้าหมายของเขาในการโค่นบริทันเนียจากภายในได้แล้ว!
